# 🎮 Beaten It

Uma aplicação web desenvolvida para centralizar, gerenciar e organizar o catálogo de jogos espalhados por diferentes plataformas (Steam, Epic Games, PlayStation, Xbox, ROMs, etc.), eliminando a dúvida sobre a posse e status de cada jogo.

## 🚀 Arquitetura e Tecnologias

- **Front-end:** React / HTML5, CSS3, JavaScript (ES6+)
- **Backend / Database:** NodeJS, Fastify, TypeScript / SQLite
- **Protocolo de Comunicação:** REST API / JSON

## ✨ Funcionalidades

- 📚 **Catálogo Unificado:** Visualização de todos os jogos pertencentes a múltiplas bibliotecas.
- 🎯 **Status de Conclusão:** Acompanhamento do progresso (*Completed*, *Shelved*, *Mastered*, etc.).
- ⏱️ **Métricas de Jogo:** Registro de tempo jogado, datas de início e término, e avaliação pessoal (Rating).
- 🕹️ **Filtro por Plataforma e Mídia:** Identificação rápida da loja de origem (Steam, Epic, PS2) e do tipo de posse (Owned, ROM, Borrowed).
